# Twitter (X) AI Auto Reply Chrome Extension (Multi-Engine)

Generate intelligent, contextual, and engaging auto-replies directly on **Twitter (X)** without needing any API keys. 

Now supports **3 selectable AI Engines** right from the extension popup!

---

## 🌟 Choose Your AI Engine

You can switch between any of these 3 modes with 1 click in the extension popup:

1. ⚡ **Gemini Nano (Built-in On-Device AI)** *(Recommended)*:
   - **0 tabs opened**.
   - 100% private, local, and works offline using your computer's GPU.
   - Built directly into Chrome via Google's Prompt API.
2. 🌐 **Headless Web (Cookie Session)**:
   - **0 tabs opened**.
   - Sends silent background requests directly using your active Google login session cookies.
3. 🗂️ **Gemini Web Tab (DOM Automation)**:
   - Automates the real [gemini.google.com/app](https://gemini.google.com/app) interface.
   - Includes an **Auto-close tab** switch so background tabs disappear automatically after reply generation!

---

## 🚀 How to Reload & Test

1. Open `chrome://extensions/` in Google Chrome.
2. Click the **Reload 🔄 icon** on the **Twitter AI Auto Reply (Gemini Web)** card.
3. Click the extension icon in your toolbar:
   - You will see the **"Choose AI Engine"** selector.
   - Select **⚡ Gemini Nano** (or Headless Web, or Web Tab).
   - The status badge will show **Ready**.
4. Test it in the popup:
   - Type a sample tweet in **"Test Selected Engine"** and click **Generate**.
5. Go to [x.com](https://x.com) / [twitter.com](https://twitter.com):
   - Click reply on any tweet.
   - Click **"✦ AI Reply"** and watch the reply auto-type smoothly with zero tabs!
